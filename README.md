# 临界制动 · 1612

中文界面的浏览器街机刹车挑战：在夜间海岸公路上控制踏板力度，减速通过弯道并停入避险区。

默认使用 3D 模式，场景右上角可切换 2D。两种视角共用同一局的距离、刹车规则和得分，切换不会重开。最佳得分仅保存在当前浏览器。

支持三种车型与三条赛道。3D 模式包含不同车身轮廓、随距离转动的车轮、刹车灯、真实曲线道路、护栏、限速牌与绿色避险区。车辆自动沿道路行驶，玩家只需控制刹车。超速入弯、踏板断裂及冲出停车区沿用现有失败规则，并呈现 3D 翻滚。设备无法启动 3D 或图形上下文丢失时回到 2D，保留当前游戏进度。

车身使用圆润座舱、弧面机盖与收窄车顶，包含窗框、轮眉、后视镜、分段灯组、格栅和轮毂细节。冷暖环境反射、车灯光晕及路面照明加强车漆层次。经典海岸路线两处道路分别平滑转向约 60° 和 80°；前轮转角为便于观察作适度放大，车身随车速轻微侧倾，跟随镜头沿后方道路移动。它们只改变 3D 表现，不改变刹车、限速及得分规则。

## 车型与赛道选择

开始界面有「更换车型」「选择赛道」入口；游戏中也可通过顶部「车型 / 赛道」或暂停、结果界面打开。可预览配置，返回时保留原挑战；进行中的挑战应用配置会明确重新开始一局。配置保存在当前浏览器，无法保存时仍可正常游玩。

- 巡航 MPV：双拼车漆、长座舱。
- 山行 SUV：蓝色车漆、高车身、较短车身。
- 赤影轿跑：红色车漆、低车顶、溜背与横向灯组。

车型仅改变外观，制动与得分规则一致。三条赛道有不同场景、曲率、限速点和停车区；2D/3D 均使用所选车型与赛道。最佳成绩按赛道保存，经典海岸路线兼容旧版最佳成绩。

| 赛道 | 全长 | 弯道位置与限速 | 停车区 |
| --- | --- | --- | --- |
| 海岸夜航 | 560 m | 180 m / 80 km/h；350 m / 55 km/h | 460–560 m |
| 山路连弯 | 640 m | 160 m / 80 km/h；300 m / 60 km/h；440 m / 45 km/h | 540–640 m |

## 玩法

- 键盘空格或触控踏板：按住加压，松开卸力，短按交替保持节奏。
- 力度超过 **1612 N**：踏板断裂、车辆翻滚，挑战失败。
- 在所选赛道的限速牌前降到目标速度；海岸默认路线仍为 80 / 55 km/h。
- 在所选赛道的绿色避险区内降至 ≤3 km/h，即获胜。
- Esc 暂停/继续，R 重开；切出窗口自动暂停。音效默认关闭，可手动开启。

**1612 N 与车辆运动模型均为虚构游戏规则，不代表实际安全阈值或驾驶指导。** 故障剧情不指向任何真实事故，也不表示真实车型存在相关缺陷。

经典 MPV 仅参考[尊界 V800 官方外观](https://hima.auto/zunjie/v800/)进行风格化绘制。3D 车辆参考[极限刹车挑战](https://brake.tp0k.us/)中的高车身、双拼色、长 MPV 座舱和纵向灯组，使用独立制作的几何与材质，未复制参考游戏源码或使用品牌标识。参考车由代码生成，并非单独的可下载模型；其[公开存档](https://github.com/TiaraBasori/BreakV800)注明版权归原作者。

所有几何、贴图均在本地生成。Three.js **0.186.1** 随站点托管于 `docs/vendor`，保留其 MIT 许可，不依赖外部 CDN、付费服务或游戏账号。

## 本地运行

游戏是无构建步骤的静态源码。可使用 Python 3 启动预览：

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory docs
```

在浏览器中打开 `http://127.0.0.1:4173/`。

使用 Node.js 运行规则及道路几何验证：

```sh
npm test
```

手动验证：默认 3D、三种车型/三条赛道的选择与预览、返回保留进度、应用重新开始、记住配置、按赛道成绩、鼠标和键盘 2D/3D 同局切换、暂停继续、翻滚重开及窄屏布局。真实手机性能和大陆网络可达性需在目标设备及网络上验证。

道路场景与实际游戏的上下文丢失验收页位于 `tests/scene-preview.html`、`tests/context-loss.html`。场景页可选择车型/赛道，检查车辆展示、首末弯道、停车区与动态通关；从仓库根目录启动静态服务后访问它们。验收页不会随 `/docs` 发布。

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，分支 `main`，目录 `/docs`。所有资源使用相对路径，支持仓库子路径部署；`docs/.nojekyll` 禁用 Jekyll 处理。

支持桌面键盘和手机 Pointer Events 触控。实体手机与网络可达性受设备和网络环境影响。

涉及共享模块的发布需同步更新 HTML 入口、样式及自有模块引用的资源版本参数，避免浏览器把新入口与旧模块缓存混用；第三方渲染库版本保持独立。
